# 🥧 Pie Time

> Focus hard. Bake pies.

Pie Time is a cozy bakery-themed Pomodoro timer built with **React** and **Tailwind CSS**. Instead of a traditional productivity app, Pie Time turns focus sessions into a delightful baking experience. Start the timer, watch your oven come to life, and earn delicious pies as rewards for staying productive.

## ✨ Features

* ⏱️ 25-minute focus timer
* ☕ 5-minute break timer
* 🔥 Animated oven states (Idle & Baking)
* ▶️ Start, Pause, and Reset controls
* 🍅 Focus / ☕ Break mode toggle
* 🎨 Custom bakery-inspired UI designed in Figma
* 📱 Responsive and clean interface

## 🛠️ Built With

* **React**
* **Vite**
* **Tailwind CSS**
* **Figma**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Dishitha0607/Pomodoro
```

Navigate into the project directory:

```bash
cd project1
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:5173
```

## 🎨 Design Inspiration

Pie Time was designed to make productivity feel warm, cozy, and rewarding. The bakery theme was created in Figma, with custom oven illustrations and playful interactions inspired by casual cooking games.
